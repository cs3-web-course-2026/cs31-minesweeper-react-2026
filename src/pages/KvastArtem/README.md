# Сапер на React — практична робота №3

Кваст Артем, КС-31-1. Сторінка гри: `/kvast-artem`.

## Запуск

З кореня репозиторію:

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Гра доступна у списку **Implementations**. На локальному сервері її також можна
відкрити за адресою `http://localhost:5173/kvast-artem`.

## Архітектура

- `index.jsx` поєднує компоненти та передає стан і обробники через props.
- `components/Board.jsx` відображає поле, керує фокусом і навігацією стрілками.
- `components/CellButton.jsx` відображає клітинку та передає дії гравця.
- `Timer`, `FlagCounter`, `RestartButton`, `GameStatus` мають окремі обов'язки.
- `hooks/useGameState.js` зберігає стан через `useReducer` та надає дії гри.
- `hooks/useTimer.js` запускає інтервал під час гри й очищає його при завершенні,
  рестарті та розмонтуванні компонента.
- `utils/board.js` містить чисті функції генерації, підрахунку сусідів,
  рекурсивного відкриття, прапорців і перевірки перемоги.
- `utils/gameReducer.js` виконує незмінювані переходи стану. Випадкові числа
  передаються з обробника дії, тому reducer не генерує випадковість під час render.
- Усі стилі обмежені CSS Modules у цій директорії.

Поле 10 × 10 містить 15 мін. Вони розміщуються при першій результативній дії.
Перший клік може потрапити на міну, як у попередній реалізації.
Перемога настає після відкриття всіх 85 безпечних клітинок.

## Керування

- Лівий клік відкриває клітинку, правий ставить або знімає прапорець.
- Tab входить у поле один раз; стрілки обирають клітинку без переходу через край.
- Enter або пробіл відкривають клітинку, F перемикає прапорець.
- Утримання F не перемикає прапорець багато разів; Ctrl+F, Command+F та Alt+F
  зберігають поведінку браузера.
- На вузькому або сенсорному екрані прихована підказка для ПК. Кнопка
  «Режим прапорця» дозволяє ставити прапорці звичайним дотиком.
- «Рестарт» скидає поле, час, прапорці та сенсорний режим.

## Перевірки

```bash
node --test src/pages/KvastArtem/tests/game.test.mjs
pnpm lint
pnpm build
```

Тести перевіряють 100 відтворюваних полів з незалежним підрахунком сусідів,
незмінюваність вхідних даних, рекурсію, прапорці, перемогу, поразку, рестарт
і захист від запізнілих тактів таймера попереднього раунду.

Додатково пройдено 17 браузерних перевірок у Microsoft Edge: роутинг,
кліки, контекстне меню, клавіатура, ліміт прапорців, завершення гри,
таймер у StrictMode та після навігації, сенсорний режим і ширина 375 px.
Реальні скриншоти гри розміщені в `screenshots/`.
