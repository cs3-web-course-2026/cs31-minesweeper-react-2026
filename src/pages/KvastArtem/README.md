# Сапер на React — практична робота №3

Кваст Артем, КС-31-1. Сторінка гри: `/kvast-artem`.

## Запуск

З кореня репозиторію:

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Гра доступна у списку **Implementations**. На локальному сервері її також можна
відкрити за адресою `http://localhost:5173/kvast-artem`.

## Архітектура

- `index.jsx` поєднує компоненти та передає стан і обробники через props.
- Спільний `Layout` уже надає єдиний `<main>`. Гра використовує іменовану
  `<section aria-labelledby>` всередині нього, без вкладеного `<main>`.
- `components/Board.jsx` відображає поле, керує фокусом і навігацією стрілками.
- `components/CellButton.jsx` відображає клітинку та передає дії гравця.
- `Timer`, `FlagCounter`, `RestartButton`, `GameStatus` мають окремі обов'язки.
- `hooks/useGameState.js` зберігає стан через `useReducer` та надає дії гри.
- `hooks/useTimer.js` запускає інтервал під час гри й очищає його при завершенні,
  рестарті та розмонтуванні компонента. Час обчислюється за `performance.now()`,
  тому затримка інтервалу не губить секунди; завершальний хід уточнює результат.
- `utils/board.js` містить чисті функції генерації, підрахунку сусідів,
  рекурсивного відкриття, прапорців і перевірки перемоги.
- `utils/gameReducer.js` виконує незмінювані переходи стану. Випадкові числа
  передаються з обробника дії, тому reducer не генерує випадковість під час render.
- Усі стилі обмежені CSS Modules у цій директорії.

Поле 10 × 10 містить 15 мін. Вони розміщуються при першому відкритті клітинки,
яка гарантовано буде безпечною. Прапорці, поставлені до цього, зберігаються.
Таймер починається з першої результативної дії, зокрема встановлення прапорця.
Перемога настає після відкриття всіх 85 безпечних клітинок.

## Керування

- Лівий клац або дотик відкриває клітинку, коли режим прапорця вимкнений.
  У режимі прапорця він ставить або знімає прапорець; вимкніть цей режим,
  щоб знову відкривати клітинки дотиком або лівою кнопкою миші.
- Правий клац ставить або знімає прапорець у будь-якому режимі.
- Tab входить у поле один раз; стрілки обирають клітинку без переходу через край.
- Enter або пробіл завжди відкривають клітинку незалежно від режиму,
  F перемикає прапорець.
- Утримання F не перемикає прапорець багато разів; Ctrl+F, Command+F та Alt+F
  зберігають поведінку браузера.
- Розділ «Керування» доступний на будь-якій ширині й початково згорнутий,
  тому підказки для ПК не відображаються постійно на телефоні.
- Кнопка «Режим прапорця» доступна на вузькому екрані та на пристроях
  із сенсорним вказівником, навіть якщо основним вказівником є миша.
- Після перемоги або поразки стрілки дозволяють переглядати поле,
  але ігрові дії вже не змінюють його.
- «Рестарт» скидає поле, час, прапорці та сенсорний режим.

## Перевірки

```bash
node --test src/pages/KvastArtem/tests/game.test.mjs
pnpm lint
pnpm build
```

22 тести перевіряють 100 відтворюваних полів з незалежним підрахунком сусідів,
незмінюваність вхідних даних, рекурсію, прапорці, перемогу, поразку, рестарт
безпечний перший хід, відхилення розріджених випадкових вибірок
і захист від запізнілих тактів таймера попереднього раунду.

Додатково пройдено 23 браузерних перевірок у Microsoft Edge: роутинг,
кліки, контекстне меню, клавіатура, ліміт прапорців, завершення гри,
таймер у StrictMode та після навігації, затримані такти, сенсорний режим,
ширина 375 px, довідка й клавіатурний перегляд завершеного поля.
Реальні скриншоти гри розміщені в `screenshots/`.
